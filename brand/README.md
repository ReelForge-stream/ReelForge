# ReelForge brand assets

**The Press:** two steel plates squeezing a white-hot frame of film. That's media being forged and compressed, which is what ReelForge does.

| File | Use |
|---|---|
| `logo-horizontal.svg` / `logo-horizontal-dark.svg` | Lockup for dark / light backgrounds (the wordmark is outlined, so no font is needed) |
| `logo-mark.svg` / `logo-mark-dark.svg` | Mark alone for dark / light backgrounds |
| `logo-mark-mono.svg`, `wordmark.svg` | Single colour (`currentColor`) |
| `app-icon.svg`, `png/app-icon-*.png` | App icon master and exports (16–1024 px) |
| `reelforge.ico` | Windows installer, uninstaller and shortcuts (16–256 px) |
| `favicon.ico` | Browser tab (16/32 px) |
| `png/social-preview.png` | GitHub social preview (Settings → Social preview), 1280×640 |
| `fonts/` | Chakra Petch (SIL Open Font License, see `fonts/OFL.txt`) |

**Colours:**

| Token | Hex | Use |
|---|---|---|
| Forge Night `base` | `#17202A` | Page background |
| Gunmetal `surface` | `#212C38` | Panels and cards |
| Plate `surface-2` | `#2B3846` | Raised and hover states |
| Frost `fg` | `#E8EDF2` | Text |
| Steel `muted` | `#93A4B5` | Secondary text |
| Ember `ember` | `#FF8A1F` | The one accent |
| Coolant `coolant` | `#5FD3A6` | Space saved |
| Danger `danger` | `#FF6B6B` | Destructive actions and failures |

The molten gradient (`#FFD25A` → `#FF8A1F` → `#F0442C`) belongs to the logo only.

**Type:** Chakra Petch for display and the wordmark; Instrument Sans for text.

**Don't:**
- recolour the frame;
- put the mark on orange;
- separate the plates from the frame;
- add glows or shadows;
- write "Reel Forge" or "REELFORGE".
